Apa itu Raiden Visuals?

Raiden Visuals adalah custom deferred configuration yang dapat mengoptimalkan performa vibrant visuals berkali kali lipat pada minecraft bedrock edition, untuk edisi VIP+ memiliki custom shader renderdragon untuk meningkatkan performa lebih jauh lagi serta memperbagus visual tanpa mengorbankan FPS!.

Panduan Instalasi

ANDROID

Untuk sistem operasi Android, diperlukan aplikasi pihak ketiga seperti MB Loader, Levi Launcher, Ambient For MCPE, atau Flarial Client agar Raiden Visual dapat berfungsi.

  • MB Loader

    Untuk MB Loader, cukup memasang file mcpack yang diberikan, lalu launch dengan shader loader MBL2 atau Fuse(Beta).

  • Levi Launcher

    Untuk Levi Launcher, perlu memasang MaterialBinLoader 2 agar Raiden Visuals dapat berfungsi.

  • Ambient For MCPE

    Untuk Ambient For MCPE, harus mengaktifkan fitur Shader Loader di dalam pengaturan launcher agar Raiden Visuals dapat berfungsi.

  • Flarial Client

    Untuk Flarial Client, harus mengaktifkan fitur Shader Loader melalui Flarial shortcut (tombol mengambang dengan logo Flarial). Setelah mengaktifkan Shader Loader di Flarial Client, wajib restart Flarial Client agar Raiden Visuals dapat berfungsi.

WINDOWS

Untuk sistem operasi Windows atau Linux, cukup memindahkan folder "renderer" di dalam file mcpack yang diberikan, lalu tempelkan di lokasi.

Untuk Minecraft Bedrock versi stable, buka isi folder "subpacks\OfficialFix" lalu pindahkan folder "renderer" nya ke C:\XboxGames\Minecraft for Windows\Content\data

Untuk Minecraft Bedrock versi preview, tidak perlu memindahkan renderer didalam folder subpacks, langsung pindahkan folder "renderer" nya ke C:\XboxGames\Minecraft Preview for Windows\Content\data

Q&A

Q : Apakah Raiden Visuals dapat langsung dipasang?

Tidak langsung. Metode pemasangan bergantung pada platform: Android memerlukan launcher yang didukung, sedangkan Windows menggunakan folder renderer sesuai panduan. Untuk iOS, periksa catatan rilis edisi yang dipakai; HynisiOS tidak disarankan untuk VIP+ v2.5.1.

Q : Apakah kompatibel dengan Vibrant Visuals Pack lain seperti Strawberry dan Prizma?

A : Ya, tentu saja kenapa tidak?

Q : Apakah kompatibel dengan shader renderdragon seperti Mirai?

A : Ya, tapi hanya untuk edisi standard bukan yang VIP+

Bagaimana cara mengoptimalkan Vibrant Visuals di Minecraft Bedrock?

Gunakan konfigurasi yang sesuai dengan versi Minecraft dan platform, ikuti panduan pemasangan, lalu uji pengaturan grafis satu per satu pada dunia dan resolusi yang sama. Jika performa belum stabil, coba kurangi render distance atau resolusi. Hasil berbeda-beda tergantung GPU, perangkat, dan pengaturan.

Apakah Raiden Visuals pasti meningkatkan FPS?

Tidak ada peningkatan FPS yang dapat dijamin untuk semua perangkat. Raiden Visuals dibuat untuk mengoptimalkan konfigurasi Vibrant Visuals, tetapi hasil aktual bergantung pada GPU, CPU, resolusi, pengaturan, dan kondisi dunia Minecraft.

Apakah Raiden Visuals merupakan shader Minecraft?

Raiden Visuals adalah custom deferred configuration untuk pipeline Vibrant Visuals Minecraft Bedrock, bukan shader mandiri yang menggantikan kebutuhan Vibrant Visuals. Cara pemasangan bergantung pada platform dan edisi.

Versi Minecraft Bedrock apa yang kompatibel dengan Raiden Visuals VIP+ v2.5.1?

Catatan rilis VIP+ v2.5.1 menyebut kompatibilitas dengan Minecraft Bedrock versi 26.60. Periksa changelog terbaru untuk mengetahui kompatibilitas versi lain.

Apakah Raiden Visuals VIP+ v2.5.1 tersedia untuk Windows?

Ya. Raiden Visuals VIP+ kini tersedia untuk Windows mulai versi 2.5.1. Ikuti panduan Windows di halaman ini dan buat cadangan folder renderer sebelum mengganti file.

Cara Mengoptimalkan Vibrant Visuals di Minecraft Bedrock

Raiden Visuals adalah custom deferred configuration untuk Vibrant Visuals di Minecraft Bedrock, bukan shader mandiri. Panduan ini menjelaskan langkah dasar memasang dan menguji konfigurasi agar sesuai dengan perangkat Anda.

  1. 1. Periksa versi game dan edisi

    Pastikan edisi dan versi Minecraft Bedrock sesuai dengan catatan rilis paket yang dipilih. Raiden Visuals VIP+ v2.5.1 mencantumkan kompatibilitas dengan Minecraft Bedrock 26.60. Versi lain dapat memiliki kompatibilitas berbeda.

  2. 2. Ikuti metode pemasangan sesuai platform

    Di Android, gunakan launcher yang tercantum pada panduan instalasi. Di Windows, ikuti petunjuk pemindahan folder renderer dan cadangkan folder asli terlebih dahulu. Untuk iOS, periksa catatan rilis; HynisiOS tidak disarankan untuk VIP+ v2.5.1.

  3. 3. Pastikan konfigurasi aktif

    Ikuti petunjuk launcher dan game untuk memeriksa apakah konfigurasi berhasil dimuat. Pada paket ini, Deferred Render Distance yang dapat diatur ke 1 chunk merupakan salah satu petunjuk bahwa konfigurasi aktif.

  4. 4. Uji performa dengan pengaturan bertahap

    Gunakan dunia, resolusi, dan kondisi pengujian yang sama. Ubah satu pengaturan setiap kali; jika performa belum stabil, coba kurangi render distance atau resolusi. Dampaknya bergantung pada perangkat dan pengaturan grafis.

  5. 5. Baca changelog dan masalah yang diketahui

    Periksa changelog edisi yang digunakan sebelum memasang atau memperbarui. Cadangkan folder renderer sebelum menggantinya, dan tinjau masalah yang diketahui jika menemukan artefak visual atau fitur yang tidak bekerja.

Catatan performa

Tidak ada konfigurasi yang dapat menjamin kenaikan FPS pada semua perangkat. Minecraft Bedrock, GPU, CPU, resolusi, texture pack, launcher, dan kondisi dunia dapat memengaruhi hasil.
